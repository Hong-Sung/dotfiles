# 공통 AI 작업 규칙 (Claude · Codex · Antigravity)

모든 프로젝트에 적용한다. 저장소 규칙과 충돌하면 프로젝트 `AGENTS.md`를 따른다.
이 파일이 원본이다: `~/.config/ai/AGENTS.md`
- Claude: `~/.claude/CLAUDE.md`에서 import
- Codex: `~/.codex/AGENTS.md`가 이 파일의 심볼릭 링크
- Antigravity: `~/.gemini/GEMINI.md`에서 include

## 1. 코딩 원칙
- **먼저 생각하기**: 가정과 모호한 해석을 밝히고, 불확실하면 묻는다. 더 단순한 방법이 있으면 알린다.
- **단순하게**: 요청하지 않은 기능·설정·일회성 추상화나 불가능한 상황을 위한 처리를 추가하지 않는다.
- **필요한 곳만 고치기**: 요청과 무관한 줄은 바꾸지 않는다. 내 변경으로 불필요해진 코드만 지우고, 다른 죽은 코드는 보고한다.
- **목표 기반 실행**: 완료 기준을 정하고 다단계 작업은 짧은 계획과 확인 방법을 먼저 밝힌다. 빌드뿐 아니라 핵심 시나리오를 확인한다.
- **최소 테스트**: 반복 중엔 변경 파일의 최소 테스트만 실행한다. 패키지·전체 테스트는 요청 시 또는 커밋 전 최종 검증에서 한 번 실행한다.
- **사용자 화면 확인**: 완료 전 실제 대상(UI, Foxglove, 브라우저 등)을 확인한다. 시뮬레이션·실험을 반복하기 전에 판단에 쓸 관측 항목을 정한다.

## 2. Git
- **커밋·push**: 사용자가 명시적으로 지시할 때만 한다(“commit”, “커밋해”, “push”). 방향 승인이나 선택은 지시가 아니며, 승인은 해당 변경 묶음에만 적용한다.
- 관련 검사 결과가 이미 통과했다면 커밋 전에 전체 테스트를 다시 돌리지 않는다.
- 병합은 `git merge --no-ff`; 완료 후 안전하면 병합 브랜치를 `git branch -d`로 삭제한다.
- 명시적 허락 없이 `--force` push하지 않는다.
- 큰 변경은 새 브랜치 작업을 먼저 제안한다.

## 3. 소통
- 한국어로 답하고 기술 용어와 코드 식별자는 원문을 유지한다.
- **결론과 행동 우선**: 간결하게 답한다. 원인 진단은 수치·로그보다 먼저 **[핵심 원인 1줄]**, **[선택 가능한 해결책/다음 액션]**을 제시한다. 반복 설명은 피한다.
- **모델 선택**: 새 작업 착수 전, 도구 사용이나 파일 수정 전에 권장 모델·reasoning 수준과 이유를 한 줄로 제시한다. 단순 작업은 빠른 기본 모델·낮은 reasoning, 복잡한 설계·진단·반복 실패는 더 강한 모델·높은 reasoning을 권한다. 난도가 바뀌면 권장을 갱신하고, 실제로 바꾸지 않은 모델은 바꿨다고 말하지 않는다.
- 웹 검색과 페이지 조회는 묻지 않고 진행한다.
- 파괴적이거나 되돌리기 어려운 작업은 판단이 모호하면 먼저 묻는다.

## 4. 작업 연속성
세 도구 간 상태는 도구 메모리가 아니라 저장소 파일에 남긴다.
- **시작**: `docs/handoff.md`를 읽고 `git log`, `git status`와 대조한다. 파일이 없거나 오래됐을 때만 세션 로그(Claude `~/.claude/projects/`, Codex `~/.codex/sessions/`)의 최근 내용을 확인한다.
- **작업 단위 종료**(완료·커밋 전·중단·도구 전환): `docs/handoff.md`를 갱신한다. 없으면 아래 형식으로 만든다.
- **슬림화**: 완료·커밋된 이전 작업은 커밋 해시 한 줄로 요약하고 약 50줄을 유지한다.
- **결정·규칙**: 사용자가 정한 설계 결정은 도구 메모리에만 두지 않고 프로젝트 `AGENTS.md`나 `docs/`에 기록한다.

`docs/handoff.md` 형식:
```markdown
# Handoff
갱신: YYYY-MM-DD HH:MM · 도구명 · 브랜치 / 마지막 커밋

## 지금 하는 일
## 상태 (완료 / 검증 결과)
## 다음 할 일
## 미해결 · 주의
## 관련 문서
```

## 5. 실시간 도구 간 협업 (`ai-bridge` MCP)
- **용도**: `ask_claude`, `ask_codex`, `ask_agy`로 코드 리뷰, 설계 교차검토, 난해한 버그의 세컨드 오피니언을 받는다.
- **읽기 전용**: 호출된 에이전트는 읽기만 한다. 파일은 현재 메인 에이전트만 수정한다.
- **효율**: 질문·경로·핵심 diff만 전달한다. 같은 주제의 후속 질문은 반환된 `session_id`를 재사용한다.
